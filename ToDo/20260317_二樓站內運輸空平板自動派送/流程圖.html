流程三：完整任務串接時序（情境 A：Q 站為空架，空平板直接送 Q）

情境：O1 有空平板（HaveFlag=1）、Q1 為空架（HaveFlag=0），OP 要從 M 區派送物料到 O1
sequenceDiagram participant OP as OP 操作員 participant SCP as SCP 前端 participant API as DispatchController participant DB as 資料庫 participant SVR as svrPair participant RCS as AGV RCS OP->>SCP: 按下派送按鈕（M區物料 → O1） SCP->>API: 呼叫派送 API API->>DB: 查詢 oPortBinding（O1 → Q1） API->>DB: 查詢 Q1 HaveFlag（!= 1，無空平板） API->>DB: 查詢 O1 HaveFlag（== 1，有空平板） API->>DB: 查詢 Q1 HaveFlag（== 0，空架可接收） API->>DB: 建立物料 oNeed（M區 → O1） API-->>SCP: 派送成功 Note over SVR: svrPair 主循環 SVR->>DB: 讀取物料 oNeed（目的地 O1） SVR->>DB: 查詢 oPortBinding（O1 → Q1） SVR->>DB: 查詢 Q1 HaveFlag（!= 1，無空平板） SVR->>DB: 查詢 Q1 HaveFlag（== 0，空架可接收） SVR->>DB: 產生空平板回收 oNeed（O1 → Q1） SVR->>DB: 物料 oNeed 跳過，不轉 oRequire Note over SVR: 處理空平板回收任務 SVR->>DB: 空平板回收 oNeed → oRequire → oMission SVR->>RCS: 派發空平板回收任務（O1 → Q1） RCS-->>SVR: 任務完成 Callback SVR->>DB: Q1 HaveFlag 更新為 1（空平板到位） Note over SVR: 下一輪循環 SVR->>DB: 讀取物料 oNeed（目的地 O1） SVR->>DB: 查詢 Q1 HaveFlag（== 1，有空平板） SVR->>DB: 物料 oNeed → oRequire → oMission SVR->>RCS: 派發物料搬運任務（M區 → O1） RCS-->>SVR: 任務完成 Callback Note over OP,RCS: 完成！物料已送達 O1，Q1 有空平板可收料

流程四：完整任務串接時序（情境 B：Q 站已有空平板，O/P 空平板送 FallbackAreas）

情境：O1 有空平板（HaveFlag=1）、Q1 已有空平板（HaveFlag=1），OP 要從 M 區派送物料到 O1。
Q1 已滿足收料條件，但 O1 的空平板需搬走才能放物料，送至 FallbackAreas。
sequenceDiagram participant OP as OP 操作員 participant SCP as SCP 前端 participant API as DispatchController participant DB as 資料庫 participant SVR as svrPair participant RCS as AGV RCS OP->>SCP: 按下派送按鈕（M區物料 → O1） SCP->>API: 呼叫派送 API API->>DB: 查詢 oPortBinding（O1 → Q1） API->>DB: 查詢 O1 HaveFlag（== 1，有空平板需搬走） API->>DB: 查詢 Q1 HaveFlag（== 1，已有空平板，無法再放） API->>DB: 依 FallbackAreas（M,Q,R）找空位（找到 M3） API->>DB: 建立物料 oNeed（M區 → O1） API-->>SCP: 派送成功 Note over SVR: svrPair 主循環 SVR->>DB: 讀取物料 oNeed（目的地 O1） SVR->>DB: 查詢 oPortBinding（O1 → Q1） SVR->>DB: 查詢 O1 HaveFlag（== 1，有空平板） SVR->>DB: 查詢 Q1 HaveFlag（== 1，已有空平板） SVR->>DB: 依 FallbackAreas 找空位（M3） SVR->>DB: 產生空平板回收 oNeed（O1 → M3） SVR->>DB: 物料 oNeed 跳過，不轉 oRequire Note over SVR: 處理空平板回收任務 SVR->>DB: 空平板回收 oNeed → oRequire → oMission SVR->>RCS: 派發空平板回收任務（O1 → M3） RCS-->>SVR: 任務完成 Callback SVR->>DB: O1 HaveFlag 更新（空平板已搬走） Note over SVR: 下一輪循環 SVR->>DB: 讀取物料 oNeed（目的地 O1） SVR->>DB: 查詢 O1 HaveFlag（!= 1，空平板已清除） SVR->>DB: 查詢 Q1 HaveFlag（== 1，有空平板可收料） SVR->>DB: 物料 oNeed → oRequire → oMission SVR->>RCS: 派發物料搬運任務（M區 → O1） RCS-->>SVR: 任務完成 Callback Note over OP,RCS: 完成！物料已送達 O1，Q1 有空平板可收料

流程五：阻擋情境（Q 站有料盤）

情境：O1 有空平板（HaveFlag=1）、Q1 有料盤（HaveFlag=3），前端直接阻擋。
sequenceDiagram participant OP as OP 操作員 participant SCP as SCP 前端 participant API as DispatchController participant DB as 資料庫 OP->>SCP: 按下派送按鈕（M區物料 → O1） SCP->>API: 呼叫派送 API API->>DB: 查詢 oPortBinding（O1 → Q1） API->>DB: 查詢 O1 HaveFlag（== 1，有空平板） API->>DB: 查詢 Q1 HaveFlag（== 3，有料盤） API-->>SCP: 錯誤：下料區有料盤，請先處理下料區 SCP-->>OP: 彈窗提示，不建立任何任務 Note over OP: OP 需先處理 Q1（取走料盤、放空平板）後再重新派送
