# TaskType 資料庫遷移

## 建立日期
2026-03-20

## 來源
由「AGV自動歸位機制」與「預調度機制」的共用前置需求衍生。原 TaskType 設定存放於 HikAGV.config（SameFloorTaskTypeMap / CrossFloorTaskTypeMap），需遷移至資料庫統一管理，並新增空車移動（EmptyMove）類型支援。

## 需求說明

### 問題背景
- 現有 TaskType 設定在 config 檔，修改需重啟服務
- 新增的歸位/預調度任務屬於「空車移動」，與現有「搬運」任務流程不同，需獨立的 TaskType
- 搬運和空車移動的 TaskType 應統一在同一處管理

### 設計決策
- **全域預設 `AGVTaskType` 保留在 config** 作為最終 fallback
- **IDLE_RETURN 和 CROSS_FLOOR_DISPATCH 暫定共用 TaskType**（同為空車移動）
- **空車移動需按路線各自定義 TaskType**（與搬運相同模式）

## 資料表設計：`oTaskTypeRoute`

| 欄位 | 型態 | 說明 |
|------|------|------|
| Id | int (PK, Identity) | 自動編號 |
| MoveType | nvarchar(20) NOT NULL | `Transport`（搬運）/ `EmptyMove`（空車移動） |
| FromFloor | nvarchar(10) NOT NULL | 起點樓層：1F, 2F, 3F, 4F |
| ToFloor | nvarchar(10) NOT NULL | 終點樓層：1F, 2F, 3F, 4F |
| TaskType | nvarchar(50) NOT NULL | 海康 RCS TaskType 代碼 |
| UseFlag | nvarchar(1) NULL | Y/N 啟用停用，預設 Y |
| Remark | nvarchar(100) NULL | 備註 |

### 查詢邏輯
```
GetTaskType(fromFloor, toFloor, moveType):
  1. 查 oTaskTypeRoute WHERE MoveType=moveType, FromFloor=fromFloor, ToFloor=toFloor, UseFlag='Y'
  2. 若有 → 返回 TaskType
  3. 若無 → 返回 AGVTaskType（config 中保留的全域預設值）
```

## 實作參照
依循 `oPortBinding` 的實作模式：
- EF Model：簡化語法、可空欄位標 `?`
- DbContext：DbSet 註冊 + OnModelCreating 配置主鍵與欄位長度
- Controller：`[Authorize]`、DI 注入、Index + DataChange（批量 CRUD）
- View：表格 + 摺疊編輯/新增、維護模式切換
- JS：insert/update/delete 狀態物件、AJAX POST
- Deploy SQL：IF NOT EXISTS 建表 + 逐筆初始資料插入
