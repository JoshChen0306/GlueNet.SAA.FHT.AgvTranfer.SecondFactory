## 單一任務完成 4 道 Gate

每個子任務完成、標記 `[x]` 之前必須全部通過：

| Gate | 檢查項 | 判定 |
|------|--------|------|
| 1. Build | 對應專案建置 | 0 error（warning 允許） |
| 2. Test | TDD: 對應測試 / 一般: 回歸測試 | 全部通過 |

## Commit 策略

- 每個子任務一個（或數個）原子 commit，message 格式：`fix(dispatch): <說明>` / `test(dispatch): <說明>` / `refactor(dispatch): <說明>`
- **T4 轉碼必為獨立 commit**（`refactor(dispatch): SqlHelper.cs 轉 UTF-8 BOM，0 邏輯變更`）
- 結構性（轉碼、加參數化多載）與行為變更（參數化套用、try/catch）分開 commit
- 版本號變更若需要 → 暫停取得使用者確認後再做（不自動執行）
