## 2. 操作員日常作業

### 2.1 物料登記（登記帳料）

在空架站點登記工單與貨架。**卡控規則（程式碼確認）：**

| 規則 | 說明 |
|------|------|
| 工單必填 | 除 **R 區（廢料）** 外，工單條碼必填 |
| 貨架條碼必填 | **J（插針室）/ H（成型後）/ I（品檢）/ K（烘烤前）/ L（烘烤後）** 五區的 RackId 必填 |
| V Cut 標記 | 在 **M 區** 勾選「V Cut 專用」→ 工單自動附加 `^VCUT`；**T 區** 登記自動標 `^VCUT^DONE`（已加工完成）|
| NG 回送標記 | **I 區（品檢）** 登記自動標 `^NG`，表品檢失敗、須回 4F 烘烤後再加工 |
| 登記結果 | 站點 `HaveFlag` 設為 `3`（料盤），記錄工單 / 貨架 / 放置時間 |

> 系統設定 `MyConfig:ShowRackIdField`（現為 `false`）控制是否顯示「貨架條碼」欄位；關閉時前端隱藏並送固定哨兵值通過後端驗證。

### 2.2 手動派送

選樓層 → 選起點區 → 選起點站 → 選終點站 → 送出。
- 可選範圍依使用者**路線權限**動態篩選（見 §3.1）。
- 派往 **O / P 上料區**時，系統自動執行「空平板回收卡控」（見流程圖文件 §1）；若下料區 / 候補區無空位會擋下並提示原因。

### 2.3 Release（空板回送）

對放有空板的站點按 Release，系統依起點區自動決定回送終點（終點寫死於程式）：

| 起點區 | 回送終點 |
|--------|---------|
| G（電梯暫存）| 3F 插針室 J 區空位 |
| K（烘烤前）| 2F 成型後 H 區空位 |
| I（品檢）| 4F 烘烤後 L1–L4（帶 NG 回送標記）|
| O / P / S / N | 依序找 M → Q → R 第一個空位 |

> **前置：** 站點須先「標記空板」（`HaveFlag=1`）才能 Release；若已有待處理任務會擋下。

### 2.4 清除物料 / 標記空板

| 操作 | 適用 | 行為 |
|------|------|------|
| 清除物料（ClearLot）| 一般站點 | 設為**空板**（`HaveFlag=1`，空板留置原位避免自動回送疊板），清工單 / 貨架 / 時間 |
| 標記空板（MarkEmptyTray）| O / P / S / N | 由料盤（3）改空板（1），清工單但**保留 RackId** |

> 兩者皆有卡控：站點若有進行中派送任務則無法操作。

### 2.5 取消任務

在派送進度列表按取消。系統以 `ParentTaskDateTime` **連動取消**父 / 子任務並從 `oNeed` 源頭清除：
- 取消跨樓層任務 → 連動取消其預調度子任務。
- 取消物料任務 → 連動取消其空平板回收子任務（O→Q）。
- 跨樓層預調度取消後 30 秒內不會立即重派（冷卻期）。

## 3. 管理員設定作業

### 3.1 路線權限管理（選單 504）

為每個使用者指派可操作的派送路線（`pUserRoute`）。
- 指派後，該使用者派送頁只顯示其有權限的**起點區與樓層 Tab**。
- `RELEASE` 類路線（ROUTE_1F_3F、ROUTE_4F_2F）不顯示於派送選單，只供 Release 使用。
- 路線清單與起終點對照見「派送路由對照表」§5。

### 3.2 上下料區綁定（選單 505）

維護 `oPortBinding`：上料區（O/P）↔ 下料區（Q）綁定與回收候補區（FallbackAreas）。
- 每次現場調整站點時須同步維護。
- 預設綁定 O1–O8、P1–P9 對應 Q1–Q9，FallbackAreas 皆為 `M,Q,R`。

### 3.3 TaskType 路由（選單 506）

維護 `oTaskTypeRoute`：樓層方向 → 海康 RCS TaskType 代碼。
- **TaskType 代碼必須與 RCS 設定一致，否則 AGV 收不到任務。**
- 目前多為 `*Test` 測試代碼，正式上線須與 RCS 確認後更新。

## 4. 常見異常排查

> 沿用 `功能說明書 §7`，並補本次新增功能。

| 現象 | 可能原因 | 排查 |
|------|---------|------|
| 物料派往 O/P 一直卡住不派 | 空平板回收卡控：下料區有料盤(3) 或候補區全滿 | 查 oPort 對應 Q 區 HaveFlag；清理 M/Q/R 候補空位 |
| 空平板回收任務重複產生 | 上輪回收任務未完成 | 查 oNeed/oRequire/oMission 是否有 `PLATE_RECOVERY` 進行中 |
| 車輛閒置很久未自動歸位 | UpdateTime>60s 判離線 / 車號非跨樓層車 / MapCode 無法解析 | 查 oShuttle.UpdateTime 與 MapCode；確認 `CrossFloorShuttleId`（現場車號 3）|
| 跨樓層預調度完成後正式任務沒接上 | Callback 未正確回傳 / pending 旗標未重置 | 查 ACC Log 的 Callback 與 oMission OkFlag |
| 取消任務後又自動重建 | 冷卻期未生效 / ParentTaskDateTime 未連動 | 查 ubCancelLog；確認預調度有帶 ParentTaskDateTime |
| AGV 收不到任務 | TaskType 與 RCS 不一致 | 查 oTaskTypeRoute 與 RCS 確認代碼 |
| 派送頁看不到應有的區域 / 樓層 | 使用者路線權限未設定 | 至路線權限管理（504）檢查 pUserRoute |
